=== Category ===

- None on Category itself

Navigation Properties:
- Products : ICollection<Product> -> Product

Delete Behavior:
- Cascade (Product.CategoryId -> Category)

=== Product ===

Inherits: BaseEntity<int>

Properties:
- Id : int (PK)
- Name : string (required)
- Description : string (required)
- NewPrice : decimal (required, decimal(18,2) via Fluent API)
- OldPrice : decimal (decimal(18,2) via Fluent API)
- CategoryId : int (required)
- Rating : double (aggregated/round-robin rating, computed manually in RatingReposiroty, not a computed column)
- Category : Category (virtual)
- Photos : List<Photo> (virtual)

Relationships:
- Many-to-one with Category (FK CategoryId)
- One-to-many with Photo (Photos collection on Product)
- Note: Product does NOT have a Ratings navigation property; the Rating->Product relationship is configured as one-to-many with no inverse navigation (Rating has FK ProductId)

Foreign Keys:
- CategoryId : int -> Category

Navigation Properties:
- Category : Category -> Category
- Photos : List<Photo> -> Photo

Delete Behavior:
- CategoryId -> Cascade (deleting a Category deletes its Products)
- Photos -> Cascade (Photo.ProductId -> Product)

=== Order ===

Inherits: BaseEntity<int>

Properties:
- Id : int (PK)
- BuyerEmail : string (required, MaxLength 256)
- OrderDate : DateTime (required, default DateTime.Now)
- Status : Status (required; stored as string MaxLength 20 via HasConversion in Fluent API)
- SubTotal : decimal (required, decimal(18,2))
- DeliveryMethodId : int (required)
- PaymentIntentId : string
- DeliveryMethod : DeliveryMethod
- OrderItems : List<OrderItem>
- ShippingAddress : ShippingAddress (owned type; stored in same "Orders" table)
- Total : decimal (read-only computed property => SubTotal + DeliveryMethod.Price; not mapped to a DB column)

Relationships:
- Many-to-one with DeliveryMethod (Fluent API: HasOne/WithMany, required, Restrict)
- One-to-many with OrderItem (Fluent API: HasMany/WithOne, FK OrderItem.OrderId, Cascade)
- OwnsOne ShippingAddress (owned entity, required)

Foreign Keys:
- DeliveryMethodId : int -> DeliveryMethod

Navigation Properties:
- DeliveryMethod : DeliveryMethod -> DeliveryMethod
- OrderItems : List<OrderItem> -> OrderItem
- ShippingAddress : ShippingAddress (owned)

Delete Behavior:
- DeliveryMethodId -> Restrict
- OrderItem.OrderId -> Cascade

Indexes:
- Index on BuyerEmail
- Composite index on (BuyerEmail, OrderDate)
